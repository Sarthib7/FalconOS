Research checks

What must be true.

  • Source boundRaw and normalized evidence stay attached to the request.
  • Freshness visibleReaders can see when the capture was observed.
  • Risk separateAn independent review can PASS, BLOCK, or return NO_DATA.

Planned research program

What we will do next.

  1. 01 / CaptureCollect source records with timestamps, request scope, and raw response bytes.
  2. 02 / NormalizeTurn source values into typed facts while keeping the original evidence attached.
  3. 03 / Form thesisState the opportunity, the decision condition, and what evidence would change the view.
  4. 04 / Test riskCheck access, liquidity, costs, stale data, and exit conditions before any mandate.
  5. 05 / Keep outcomeAttach later decisions and outcomes to the earlier record so the next run can inspect its history.
